## Отчёт по ДЗ к занятию «Базовые аналитические витрины»

<hr>

### **Задача:** 

Создать аналитическую витрину для расчета заработной платы сотрудников в рамках их должности и зарплатной ставки по готовой структуре таблиц БД.

<hr>

### *Результат:*

Скрипт для создания табиц и заполнения их данными был выдан преподавателем вмете с ДЗ.

Построить витрину можно несколькими способами.
Я выбрал следующий:

1. Создать view полностью совпадающий по стрктуре полей с витриной.
2. Создать таблицу витрины.
3. Скопировать данные из view в таблицу.

View в случае Postgesql можно создать одним запросом с CTE:

```sql
create view employee_salary_view AS
-- в витрине нужно сгруппировать данные по полётам: количество полётов и количество часов
-- таблица flights является таблицей факов
-- присоединяем к ней дополнительные поля из таблиц employee и airports
-- также будем считать, что оплата производится по фактическому времени полёта
-- CTE flight_details дополняет таблицу flights полями, необходимыми для агрегации данных полётов
with flight_details as (
select
    -- поля таблицы flights
    f.flight_no,
    f.status,
    -- фактическое количество часов, потраченное на полёт
    coalesce(extract(epoch from f.actual_arrival - f.actual_departure)/3600, 0)  as actual_flight_hours,
    -- коэффициент для международных рейсов
    case
        when a_dep.country = a_arr.country then 1.0
        else 1.2
    end as salary_coeff,
    -- поля таблицы employee
    e.employee_id,
    e.position,
    coalesce(e.salary, 0) as hour_rate,
    e.valid_from_dt,
    e.valid_to_dt
from
    flights f
    left join 
    -- соединяем с нужной версией сотрудника, ориентируясь на дату полёта
    employee e on (f.employee_id = e.employee_id and date(f.actual_departure) >= e.valid_from_dt and date(f.actual_departure) <  e.valid_to_dt)
    left join
    -- соединяем с аэропортом вылета
    airports a_dep on (f.departure_airport = a_dep.airport_code)
    left join
    -- соединяем с аэропортом прибытия
    airports a_arr on (f.arrival_airport = a_arr.airport_code)
where
  -- учитываем только выполненные рейсы
  UPPER(f.status)='ARRIVED'
), 
-- на основании flight_details можем посчитать размер оплаты за каждый рейс с учётом коэффициента
flights_with_salary as (
select
    fd.actual_flight_hours * fd.hour_rate * fd.salary_coeff as actual_salary,
    fd.*  
from 
  flight_details fd
), 
-- агрегируем полученные данные - считаем сумму оплаты по всем полётам и количество полётов
employee_flight_count as (
select
  -- количество employee_id в flights_with_salary определяет сколько полётов выполнил конкретный сотрудник
  count(fws.employee_id) as flight_cnt, 
  sum(fws.actual_salary) as actual_salary_gross, 
  fws.employee_id
from
  flights_with_salary fws
group by
  fws.employee_id
)
-- определение view
select
    e.employee_id,
    e."position",
    e.salary,
    efc.flight_cnt,
    efc.actual_salary_gross as salary_gross,
    e.valid_from_dt,
    e.valid_to_dt
from
    employee_flight_count efc
    left join 
    employee e on (efc.employee_id = e.employee_id);
```

Создать таблицу витрины можно следующим скриптом:

```sql
CREATE TABLE dm_employee_salary (
    employee_id      INT   NOT NULL,
    position         TEXT  NOT NULL,
    salary           FLOAT NOT NULL,
    flight_cnt       INT   NOT NULL,
    salary_gross     FLOAT NOT NULL,
    valid_from_dttm  DATE  NOT NULL,
    valid_to_dttm    DATE  NOT NULL
);
```

Скопировать данные в витрину можно следующим запросом:

```sql
INSERT INTO dm_employee_salary (
    employee_id,
    position,
    salary,
    flight_cnt,
    salary_gross,
    valid_from_dttm,
    valid_to_dttm
)
SELECT
    employee_id,
    position,
    salary,
    flight_cnt,
    salary_gross,
    valid_from_dt,
    valid_to_dt
FROM employee_salary_view;
